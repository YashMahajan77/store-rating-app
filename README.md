# ⭐ Store Rating Application

A full-stack web application for managing stores, users, and store ratings with role-based access.

## 🚀 Features

### 👤 Normal User
- User registration and login
- Browse available stores
- Search stores
- Sort stores
- View store ratings
- Submit ratings
- Update ratings
- Change password
- Logout

### 👨‍💼 Store Owner
- Secure login
- Store owner dashboard
- View store rating information
- View average ratings

### 🛠️ Administrator
- Admin login
- Manage users
- Manage store owners
- Manage stores
- Role-based access control

## 🔐 Authentication & Security

- JWT-based authentication
- Password hashing with bcrypt
- Role-based authorization
- Protected backend routes

## 🧰 Tech Stack

- React.js
- JavaScript
- HTML
- CSS
- Vite
- Node.js
- Express.js
- PostgreSQL
- JWT
- bcryptjs

## 🎯 Project Objective

This project was developed to gain practical experience in full-stack web development, REST APIs, database connectivity, authentication, authorization, and GitHub.
